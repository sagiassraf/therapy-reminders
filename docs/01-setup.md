# מדריך הקמה חד פעמית

את המדריך הזה עושים פעם אחת בלבד. אחרי זה קליטת כל מטפל חדש לוקחת כחמש דקות (מדריך 02).

סדר העבודה: גוגל, וואטסאפ, קלאודפלר, תבנית המטפלים, בדיקה.

---

## שלב 1: המערכת המרכזית בגוגל

1. פותחים גיליון חדש ב-Google Sheets בחשבון שלך. שם מומלץ: "תזכורות - לוח בקרה".
2. בתפריט: הרחבות ← Apps Script.
3. מוחקים את הקוד שמופיע, ויוצרים שלושה קבצים עם התוכן מהתיקייה:

```
central/Code.gs
central/WhatsApp.gs
central/Sheet.gs
```

4. מציגים את קובץ ההגדרות: גלגל השיניים (הגדרות הפרויקט) ← מסמנים את האפשרות להצגת קובץ המניפסט. מחליפים את התוכן של הקובץ בתוכן של:

```
central/appsscript.json
```

5. בוחרים בפונקציה `setup` ולוחצים "הפעלה". מאשרים את ההרשאות.
6. ביומן ההפעלה יופיע קוד ארוך. שומרים אותו בצד, הוא ישמש בשלב 3:

```
INTERNAL_TOKEN
```

7. פריסה: לוחצים "פריסה" ← "פריסה חדשה" ← סוג: אפליקציית אינטרנט.
   - הפעלה בתור: אני
   - למי יש גישה: כל אחד
8. מעתיקים את כתובת האפליקציה (מסתיימת ב-`/exec`). זו "הכתובת המרכזית".

> חשוב: כשמשנים קוד בעתיד, עושים "ניהול פריסות" ← עריכה ← גרסה חדשה. כך הכתובת נשארת אותה כתובת.

## שלב 2: וואטסאפ עסקי (מטא)

צריך מספר טלפון שלא מחובר לאפליקציית וואטסאפ רגילה. אפשר כרטיס סים חדש או מספר וירטואלי.

1. נכנסים לאתר המפתחים של מטא ויוצרים אפליקציה מסוג Business:

```
https://developers.facebook.com/apps
```

2. מוסיפים לאפליקציה את המוצר WhatsApp. נוצר חשבון עסקי ומספר בדיקה.
3. מוסיפים את המספר האמיתי שלך ומאמתים אותו ב-SMS.
4. מוסיפים אמצעי תשלום בחשבון העסקי.
5. יוצרים טוקן קבוע:
   - בהגדרות העסק ← משתמשי מערכת ← הוספה (תפקיד מנהל).
   - משייכים אליו את האפליקציה ואת החשבון העסקי.
   - יוצרים טוקן עם ההרשאות:

```
whatsapp_business_messaging
whatsapp_business_management
```

6. רושמים בצד שלושה ערכים:
   - הטוקן הקבוע.
   - מזהה מספר הטלפון (מופיע במסך ההגדרות של וואטסאפ באפליקציה).
   - הסוד של האפליקציה (בהגדרות האפליקציה ← בסיסי).

7. חוזרים לסקריפט המרכזי ← הגדרות הפרויקט ← מאפייני סקריפט. מוסיפים:

| מאפיין | ערך |
|---|---|
| `WA_TOKEN` | הטוקן הקבוע |
| `WA_PHONE_ID` | מזהה מספר הטלפון |
| `TEST_PHONE` | הטלפון האישי שלך, לבדיקות |

### שלוש תבניות הודעה

במנהל התבניות של וואטסאפ יוצרים שלוש תבניות.
קטגוריה: שירות (Utility). שפה: עברית.
שמות התבניות חייבים להיות בדיוק כמו כאן.

**תבנית 1**

```
reminder_24h
```

גוף ההודעה:

> שלום {{1}}, זוהי תזכורת לפגישה שלך עם {{2}} ביום {{3}} בשעה {{4}}. נשמח לדעת אם את/ה מגיע/ה 🙏

שני כפתורי תשובה מהירה, בסדר הזה:
1. מאשר/ת הגעה ✅
2. צריך/ה לבטל ❌

**תבנית 2**

```
reminder_1h
```

גוף ההודעה:

> היי {{1}}, תזכורת: הפגישה שלך עם {{2}} מתחילה היום בשעה {{3}}. נתראה!

אותם שני כפתורים, באותו סדר.

**תבנית 3** (נשלחת למטפל כשלקוח מבטל)

```
therapist_cancel_alert
```

גוף ההודעה:

> עדכון: {{1}} ביטל/ה את הפגישה שנקבעה ליום {{2}} בשעה {{3}}. השעה התפנתה ביומן.

ללא כפתורים.

> הסדר של הכפתורים חשוב: הראשון תמיד "מאשר", השני תמיד "מבטל".
> אישור תבנית לוקח בדרך כלל מכמה דקות ועד יום.

## שלב 3: קלאודפלר (מקבל את הלחיצות על הכפתורים)

1. נרשמים בחינם ב:

```
https://dash.cloudflare.com
```

2. בתפריט: Workers ← יצירה ← Worker חדש. נותנים שם ופורסים.
3. לוחצים "עריכת קוד", מחליפים הכול בתוכן של הקובץ הבא, ופורסים:

```
worker/worker.js
```

4. בהגדרות ה-Worker ← משתנים וסודות, מוסיפים ארבעה ערכים מסוג סוד:

| משתנה | ערך |
|---|---|
| `VERIFY_TOKEN` | מילה שאתה ממציא, למשל מחרוזת אקראית |
| `APP_SECRET` | הסוד של האפליקציה ממטא |
| `CENTRAL_URL` | הכתובת המרכזית משלב 1 |
| `INTERNAL_TOKEN` | הקוד משלב 1 |

5. מעתיקים את כתובת ה-Worker (מסתיימת ב-`workers.dev`).
6. חוזרים לאפליקציה במטא ← WhatsApp ← הגדרות ← Webhook:
   - כתובת: כתובת ה-Worker
   - טוקן אימות: אותה מילה שכתבת ב-`VERIFY_TOKEN`
   - לוחצים אימות ושמירה.
   - מסמנים מנוי לשדה:

```
messages
```

## שלב 4: תבנית הגיליון למטפלים

זה הגיליון שכל מטפל יקבל עותק שלו.

1. יוצרים גיליון חדש בשם "תזכורות וואטסאפ".
2. הרחבות ← Apps Script. מדביקים את התוכן של:

```
connector/Code.gs
```

3. מציגים את קובץ המניפסט (כמו בשלב 1) ומדביקים את התוכן של:

```
connector/appsscript.json
```

4. בשורה הזו בראש הקוד, מחליפים את הטקסט בכתובת המרכזית משלב 1:

```
const CENTRAL_URL = 'PASTE_CENTRAL_WEB_APP_URL_HERE';
```

5. שומרים. **לא מפעילים** את התבנית עצמה.
6. מכינים קישור העתקה: לוקחים את הקישור של הגיליון ומחליפים את הסוף שלו:

```
.../edit  ←  .../copy
```

7. משתפים את הגיליון: "כל מי שיש לו את הקישור" עם הרשאת צפייה.

זה הקישור ששולחים לכל מטפל חדש.

---

## שלב 5: בדיקה

1. בגיליון הבקרה ← תפריט "תזכורות" ← "שליחת הודעת בדיקה". אמורה להגיע אליך תזכורת לדוגמה.
2. מוסיפים את עצמך כמטפל בדיקה (תפריט ← "הוספת מטפל/ת") ומפעילים עותק של התבנית בחשבון בדיקה, לפי מדריך 02.
3. בחשבון הבדיקה יוצרים איש קשר בשם "בדיקה תזכורת" עם הטלפון שלך.
4. יוצרים ביומן פגישה בשם "בדיקה תזכורת" בעוד שעה ועשר דקות.
5. אחרי עד עשר דקות אמורה להגיע אליך תזכורת שעה לפני.
6. לוחצים "צריך/ה לבטל":
   - אמורה להגיע תשובה "קיבלנו".
   - הטלפון של המטפל אמור לקבל התראה.
   - תוך עשר דקות הכותרת ביומן תתחיל ב-❌.

אם משהו לא עובד, הלשונית Log בגיליון הבקרה מראה את השגיאה.
